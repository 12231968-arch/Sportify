# Sportify Flutter MVP

A starter Flutter mobile app for browsing sports facilities and making demo reservations.

## Run in Android Studio
1. Extract this ZIP.
2. Open the `sportify_flutter` folder in Android Studio.
3. Open the terminal in the project folder and run:
   - `flutter pub get`
   - `flutter run`
4. Choose an Android emulator or connect an Android phone with USB debugging enabled.

## Included
- Home dashboard and sports categories
- Explore facilities with sport filters and search field UI
- Facility cards with location, rating, and hourly price
- Booking form with radio buttons, checkboxes, dropdowns, date picker, and time picker
- Confirmation flow and My Bookings list
- Profile screen

## Demo limitations
- Facility data and prices are sample data.
- Reservations are stored in app memory only and reset when the app restarts.
- Login, backend/database, real availability, payments, maps, and notifications are not connected yet.
- No real booking is sent to a facility.

## Next development step
Connect Firebase or another backend, then add authentication and persistent reservations after the UI and booking flow are approved.
